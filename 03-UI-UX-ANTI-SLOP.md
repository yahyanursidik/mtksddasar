# UI/UX & Anti-Slop Rules — Math SD MVP

## 1. Arah Visual

Karakter:

- playful;
- bersih;
- hangat;
- modern;
- nyaman untuk usia SD;
- tidak kekanak-kanakan berlebihan;
- tidak menyerupai dashboard SaaS;
- tidak penuh dekorasi.

Tujuan utama visual adalah **membantu belajar matematika**.

## 2. Anti-Slop

Gunakan sebagai referensi rules:

https://github.com/miqdadbadjuber/anti-slop

Tambahkan aturan proyek berikut.

## 3. Larangan UI

Jangan gunakan:

- hero gradient generik;
- glassmorphism;
- purple-blue gradient khas AI;
- floating orb;
- kartu bertumpuk tanpa fungsi;
- icon sparkle berlebihan;
- badge untuk semua hal;
- mascot generik;
- confetti setiap jawaban;
- emoji sebagai dekorasi utama;
- tiga kolom card untuk setiap halaman;
- dashboard enterprise untuk anak;
- copywriting seperti "Unlock your potential";
- ilustrasi AI dekoratif yang tidak membantu pembelajaran.

## 4. Satu Layar, Satu Fokus

Pada halaman latihan:

```text
            8 + 7

          [ jawaban ]

          Periksa
```

Informasi sekunder harus berada di bawah.

## 5. Angka Sebagai Hero

Gunakan ukuran besar untuk:

- soal;
- angka;
- operator;
- hasil sementara.

Visual hierarchy harus memudahkan anak mengetahui apa yang sedang dikerjakan.

## 6. Warna Harus Bermakna

Warna digunakan untuk:

- membedakan puluhan dan satuan;
- mengelompokkan objek;
- menunjukkan bagian yang sedang dihitung;
- memperlihatkan transformasi.

Jangan gunakan terlalu banyak warna hanya untuk dekorasi.

## 7. Typography

Gunakan font sans-serif yang:

- ramah;
- mudah dibaca;
- bentuk angka jelas;
- angka 1, 6, 9, 0 tidak mudah tertukar.

Gunakan maksimal 2 family font.

## 8. Layout

Maksimum width konten belajar:

```text
720–960px
```

Untuk latihan, preferensi:

```text
480–720px
```

Gunakan whitespace besar.

## 9. Tombol

Primary CTA:

- besar;
- mudah disentuh;
- teks jelas.

Contoh:

- Mulai
- Coba
- Periksa
- Lanjut
- Lihat Cara

Hindari:

- Continue Learning Journey
- Explore More
- Unlock
- Discover

## 10. Navigasi Student

Maksimal:

```text
Beranda
Belajar
Latihan
Progres
```

Pada MVP, bahkan dapat dimulai dengan:

```text
Beranda
Belajar
Latihan
```

## 11. Respons Jawaban

### Benar

Gunakan feedback tenang:

> Tepat.

Kemudian lanjut.

### Salah

Gunakan:

> Belum tepat.

Berikan opsi:

- Coba lagi;
- Petunjuk;
- Lihat cara.

## 12. Animasi

Animasi hanya jika mendukung pemahaman.

Contoh baik:

- counters bergabung;
- benda berkurang;
- kelompok terbentuk;
- base-ten regrouping;
- transisi concrete → pictorial → abstract.

Contoh buruk:

- bouncing card;
- spinning icon;
- continuous floating;
- decorative parallax.

## 13. Accessibility

Minimum:

- keyboard usable;
- semantic HTML;
- focus state jelas;
- contrast memadai;
- reduced motion;
- aria-label pada manipulatif interaktif;
- touch target minimal nyaman;
- tidak bergantung pada warna saja.

## 14. Responsive

Prioritas viewport:

1. tablet;
2. desktop;
3. mobile.

Tablet penting karena sangat cocok untuk aktivitas belajar anak.

## 15. Visual Objects

Gunakan bentuk sederhana:

- lingkaran;
- kotak;
- batang;
- garis bilangan;
- ten-frame;
- array.

Tidak perlu ilustrasi manusia atau karakter.
